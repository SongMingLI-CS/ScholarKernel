## 实施

- `document-service.ts`、`/api/source`、服务端 FileTool：以当前会话用户和已保存 Document ID 查询文档，移除任意本机路径读取。历史 `path` 工具参数仅作为 Document ID 的兼容别名，不再代表系统路径。文档上传、编辑和 PDF 预览接口保留。
- `owned-messages.ts`：事务内确认会话归属；消息查找和更新条件包含消息 ID、会话 ID 和用户归属。新增同 ID 冲突返回 409，不再全局 upsert 修改其他记录。
- `intervention-service.ts`：先查询 Job 归属、状态、检查点和匹配的待决节点，再记录决定并唤醒执行。新增 AgentIntervention 表，Job/节点唯一约束保证同一决定重复提交可确认而不重复处理。冲突决定返回 409。旧客户端本地工作流仍保留本地 gate；服务端 gate 绑定用户和 Job。
- 搜索与模型调用日志不再记录密钥、请求体、检索词、原始规划和用户输入；API 错误使用限定字段的诊断日志。错误详情仍可在所属请求中向用户反馈，不作为公共日志。
- 生产配置默认要求会话；OAuth-only 配置不再误入开发单租户模式；生产代理缺少认证配置时拒绝服务。未执行身份认证测试或攻击验证。
